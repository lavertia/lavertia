# Lavertia roadmap

## v0.1: Composable foundation — in progress

- [x] Component base contract and immutable builders
- [x] Specialized contracts for Table, Field, Infolist and Action
- [x] Nested layouts (Column, Row, Card), safe JSON serializer
- [x] Minimal Table / TextColumn / Infolist / TextEntry / TextInput / Action
- [x] Inertia page abstraction and initial Vue renderer
- [x] PHP tests and local smoke scripts
- [ ] Full Composer dependency integration and Vue/Vite browser tests
- [ ] First production app integration

## v0.2: Component runtime

- [ ] Typed component registry for custom PHP / Vue components
- [ ] Form, validation errors and server-side submit actions
- [ ] Tables with independent pagination, sorting, filters, Eloquent queries
- [ ] Component-scoped state and partial async data refresh
- [ ] Authorization / tenancy regression tests
- [ ] UX/accessibility/RTL tests

## v0.3: Developer experience

- [ ] Panel provider, configurable navigation, clusters and layouts
- [ ] Resource scaffold as optional higher-level abstraction
- [ ] Plugin contracts, docs site and versioned release workflow
